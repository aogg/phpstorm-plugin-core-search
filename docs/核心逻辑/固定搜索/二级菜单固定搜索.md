# 二级菜单固定搜索显示逻辑

## 概述

二级菜单固定搜索是 PhpStorm 插件中的一个核心功能，作为"搜索核心"右键菜单的子项，提供4种固定的代码搜索类型。该功能始终显示，无需特殊条件即可使用。

## 菜单结构

### 父菜单："搜索核心"
- **注册位置**: `EditorPopupMenu` (编辑器右键菜单)
- **显示条件**: 始终可见 (`isEnabledAndVisible = true`)
- **菜单类型**: 弹出组菜单 (`popup="true"`)
- **菜单文本**: "搜索核心"
- **描述**: "根据 @core 注解搜索方法调用位置"

### 子菜单组成
```
搜索核心
├── [动态@core关键词项] (条件显示)
├── ────────────────── (分隔线)
├── 自动发现 (二级菜单)
└── 固定搜索 (二级菜单)
    ├── 构造调用
    ├── 静态调用
    ├── 常量
    └── 属性
```

## 固定搜索二级菜单详细逻辑

### 菜单定义
- **类名**: `FixedSearchActionGroup`
- **继承**: `ActionGroup("固定搜索", "固定类型的搜索", null), DumbAware`
- **菜单文本**: "固定搜索"
- **描述**: "固定类型的搜索"
- **弹出组**: `isPopupGroup = true`

### 显示条件
```kotlin
override fun update(e: AnActionEvent) {
    e.presentation.isEnabledAndVisible = true  // 始终显示
    e.presentation.text = "固定搜索"
    e.presentation.description = "固定类型的搜索"
    e.presentation.isPopupGroup = true
}
```

### 子项生成逻辑
```kotlin
override fun getChildren(e: AnActionEvent?): Array<AnAction> {
    if (e == null) return emptyArray()

    return arrayOf(
        FixedSearchConstructorAction(),   // 构造调用
        FixedSearchStaticAction(),        // 静态调用
        FixedSearchConstantAction(),      // 常量
        FixedSearchPropertyAction()       // 属性
    )
}
```

### 4个固定搜索项详情

#### 1. 构造调用 (`FixedSearchConstructorAction`)
- **菜单文本**: "构造调用"
- **描述**: "搜索构造调用"
- **搜索逻辑**:
  - 搜索当前类的直接 `new` 构造调用
  - 搜索所有子类的 `new` 构造调用
  - 递归查找所有子类及其子类

#### 2. 静态调用 (`FixedSearchStaticAction`)
- **菜单文本**: "静态调用"
- **描述**: "搜索静态方法调用"
- **搜索逻辑**: 搜索类的静态方法调用位置

#### 3. 常量 (`FixedSearchConstantAction`)
- **菜单文本**: "常量"
- **描述**: "搜索常量使用"
- **搜索逻辑**: 搜索类中常量的使用位置

#### 4. 属性 (`FixedSearchPropertyAction`)
- **菜单文本**: "属性"
- **描述**: "搜索属性访问"
- **搜索逻辑**: 搜索类属性的访问和使用位置

## 搜索执行流程

### PHP类解析
每个固定搜索项都包含相同的PHP类解析逻辑：
1. **优先级1**: 直接选中的PSI元素（如果选中的是PhpClass）
2. **优先级2**: 从PSI文件解析首个PhpClass
3. **兜底**: 通过编辑器文档获取PSI文件

### 搜索范围
- **作用域**: `GlobalSearchScope.projectScope(project)` (整个项目范围)
- **搜索方式**: 使用 `ReferencesSearch.search()` 查找引用

### 结果展示
搜索结果按优先级尝试以下展示方式：
1. **首选**: 自定义工具窗口 (`AutoDiscoverUiHelper.showAutoDiscoverToolWindow`)
2. **备选**: 自定义弹窗 (`AutoDiscoverUiHelper.showCustomUsagesPopup`)
3. **兜底**: 标准用法视图 (`UsageViewManager.showUsages`)

### 异步处理
所有搜索都在后台线程执行：
```kotlin
ProgressManager.getInstance().run(object : Task.Backgroundable(project, "固定搜索：${搜索类型}", true) {
    override fun run(indicator: ProgressIndicator) {
        ApplicationManager.getApplication().runReadAction {
            performSearch(project, indicator, phpClass)
        }
    }
})
```

## 通知机制
- **成功通知**: 使用 `NotificationType.INFORMATION`
- **错误通知**: 使用 `NotificationType.ERROR`
- **通知组**: "core-search"
- **标题**: "固定搜索"

## 线程安全
- **更新线程**: `ActionUpdateThread.BGT` (后台线程)
- **PSI访问**: 在 `runReadAction` 中进行，确保线程安全
- **UI更新**: 在 `invokeLater` 中更新界面

## 日志记录
所有重要操作都有详细的日志记录：
- 类解析结果
- 搜索开始/结束
- 找到的结果数量
- 异常信息

## 异常处理
- PSI访问异常被捕获并记录
- 搜索过程中的异常被捕获并显示错误通知
- UI显示失败时自动降级到备选方案
