# 固定搜索-对象方法调用：搜索逻辑

## 功能概述

固定搜索-对象方法调用功能用于搜索当前PHP类的对象方法调用位置，包括：
- 当前类的所有对象方法（非静态、非私有方法）
- 父类的继承对象方法
- 在项目范围内所有对这些方法的调用位置

## 搜索流程

### 1. 方法收集阶段
- **收集范围**：当前类及其所有父类的非静态、非私有方法
- **过滤条件**：排除静态方法和私有方法
- **递归处理**：沿着继承链向上收集父类方法，避免重复收集

### 2. 引用搜索阶段
- **搜索范围**：整个项目范围（GlobalSearchScope.projectScope）
- **搜索目标**：每个收集到的方法的所有引用位置
- **分批处理**：采用方法级分批（每批3个方法）和引用级分批（每批20个引用）

### 3. 过滤验证阶段
- **对象调用识别**：通过`->`操作符识别对象方法调用，排除静态调用（`::`）
- **实例类型验证**：使用IntelliJ平台的类型推断引擎验证调用对象是否为目标类的实例
- **精确匹配**：只保留类型匹配的调用，过滤掉类型不匹配或无法推断的调用

### 4. 结果展示阶段
- **增量显示**：每5秒或累积10个结果时更新UI，避免长时间无响应
- **结果格式**：显示调用位置、方法名和定义类信息
- **多窗口支持**：优先使用自动发现工具窗口，降级到标准查找视图

## 异常处理机制

### 索引异常处理
- **IndexNotReadyException**：等待索引准备或重试搜索
- **类型推断失败**：记录日志并跳过，无法推断的调用不计入结果

### UI线程安全
- 所有PSI访问都在ReadAction中执行
- UI更新通过invokeLater确保在EDT中执行
- 进度更新和取消检查在合适时机进行

## 使用场景

适用于以下情况：
- 查看某个类的方法在项目中被如何使用
- 分析类的使用模式和调用链
- 重构前了解方法的调用分布
- 代码审查时检查方法的使用情况

此功能结合了精确的类型分析和高效的性能优化，能够快速准确地找到相关的方法调用位置。
