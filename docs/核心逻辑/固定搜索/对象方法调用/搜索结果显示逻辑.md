# 固定搜索-对象方法调用：搜索结果显示逻辑

## 概述

搜索结果显示逻辑负责将过滤后的对象方法调用结果以直观、可交互的方式呈现给用户。系统使用专用工具窗口进行显示，如果显示失败则直接报错通知用户。

## 显示流程

### 1. 增量显示机制
- **触发时机**：每5秒或累积10个结果时立即显示
- **异步执行**：通过 `ApplicationManager.invokeLater` 确保UI线程安全
- **实时反馈**：避免长时间等待，提升用户体验

### 2. 显示策略
```kotlin
// 显示策略：专用工具窗口
AutoDiscoverUiHelper.showAutoDiscoverToolWindow(project, currentUsages, "固定搜索-对象方法调用")
```

## UI组件架构

### 1. 工具窗口 (Tool Window)
- **位置**：底部面板 (`ToolWindowAnchor.BOTTOM`)
- **标识**：`Auto Discover Results`
- **特性**：支持多Tab、持久化、可调整大小

### 2. 分屏布局
- **左侧面板**：树形结果列表 (40%)
- **右侧面板**：代码预览区域 (60%)
- **分割条**：可调整比例，最小尺寸限制

### 3. 控制组件
- **预览开关**：`JCheckBox("显示预览", true)`
- **标题栏**：显示搜索类型和结果统计

## 结果组织结构

### 1. 三层树形结构
```
搜索结果
├── 目标方法名 (数量)
│   ├── 调用方法名 (数量)
│   │   ├── 具体调用行内容 — 相对路径
│   │   ├── 具体调用行内容 — 相对路径
│   │   └── ...
│   └── ...
└── ...
```

### 2. 分组策略
- **第一层**：按目标方法名分组（无法解析时归入"其他"）
- **第二层**：按调用方法名分组
- **第三层**：具体调用位置和代码行

### 3. 显示格式
- **叶子节点**：`[调用代码行内容] — [相对路径]`
- **分组节点**：`[方法名] ([数量])`
- **提示信息**：鼠标悬停显示完整绝对路径

## 预览功能

### 1. 预览策略
```kotlin
// 优先尝试方法级预览
val method = PsiTreeUtil.getParentOfType(element, Method::class.java)
createEditorForMethodPreview(project, method, title, targetLine)

// 如果方法预览失败，尝试文件级预览
createEditorForFileAtLine(project, filePath, line, title)

// 如果都失败，使用文本预览
JBTextArea(previewText)
```

### 2. 编辑器特性
- **只读模式**：`editor.isViewer = true`
- **统一配色**：使用全局配色方案
- **智能滚动**：自动定位到调用行，居中显示
- **高亮支持**：临时高亮调用行，自动消失

### 3. 滚动优化
- **延迟滚动**：等待编辑器组件完全显示后滚动
- **备用方案**：外层滚动面板 + 编辑器内部滚动
- **位置验证**：确认滚动成功，失败时重试

## 交互操作

### 1. 树节点选择
- **单选模式**：`TreeSelectionModel.SINGLE_TREE_SELECTION`
- **实时预览**：选择节点立即更新右侧预览
- **自动展开**：首次显示时展开前几个节点

### 2. 双击跳转
- **文件定位**：`OpenFileDescriptor(project, vf, line, 0).navigate(true)`
- **精确跳转**：定位到具体行和列

### 3. 鼠标交互
- **点击高亮**：点击预览区域临时高亮对应行
- **工具提示**：显示完整文件路径

## 性能优化

### 1. 资源管理
- **编辑器复用**：避免频繁创建/销毁编辑器
- **内存清理**：选择新节点时释放旧编辑器资源
- **GC协作**：主动触发垃圾回收清理引用

### 2. UI响应性
- **异步加载**：所有PSI操作在ReadAction中执行
- **批次处理**：避免一次性更新大量UI元素
- **延迟执行**：使用Alarm实现定时任务

### 3. Tab管理
- **智能重用**：相同搜索条件重用现有Tab
- **资源释放**：Tab关闭时自动清理编辑器资源
- **计数限制**：防止Tab数量无限增长

## 异常处理

### 显示失败处理
- **直接报错**：显示失败时直接弹出错误通知
- **日志记录**：详细记录异常信息便于调试
- **用户提示**：通过 Notification 系统告知用户显示失败

## 样式和配色

### 1. 高亮样式
- **搜索关键词**：黄色背景高亮
- **调用行**：浅蓝色临时高亮（1秒后消失）
- **选择状态**：系统默认选择样式

### 2. 字体和布局
- **标题字体**：粗体显示
- **等宽字体**：代码预览使用等宽字体
- **间距控制**：合理的外边距和内边距

## 异常处理

### 1. UI线程安全
- **invokeLater**：所有UI更新在EDT中执行
- **异常隔离**：UI异常不影响搜索进程
- **日志记录**：详细记录UI操作异常

### 2. 资源清理
- **编辑器释放**：`EditorFactory.releaseEditor(editor)`
- **监听器清理**：移除不需要的事件监听器
- **内存泄漏防护**：确保所有引用正确释放

这个显示逻辑设计充分考虑了用户体验、性能优化和错误处理，确保功能的稳定性和可靠性。
