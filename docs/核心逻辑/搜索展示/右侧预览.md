# 右侧预览技术实现详解

## 核心技术栈

### IntelliJ Platform Editor API
- **EditorFactory**: 创建只读编辑器实例
- **EditorEx**: 扩展编辑器接口，支持配色方案设置
- **MarkupModel**: 管理代码高亮和标记
- **FileDocumentManager**: 获取文件的文档对象

### PSI (Program Structure Interface)
- **PsiElement**: PSI元素基础接口
- **Method**: PHP方法PSI元素
- **PsiTreeUtil**: PSI树操作工具类
- **PsiDocumentManager**: PSI文档管理器

### Swing UI 组件
- **JPanel**: 预览面板容器
- **JBScrollPane**: 带滚动条的面板
- **JBTextArea**: IntelliJ风格的文本区域
- **JSplitPane**: 分割面板（左右分屏）

### 预览内容获取

#### 方法源码提取
```kotlin
fun getMethodPreviewText(method: Method, contextLines: Int = 3): String {
    val containingFile = method.containingFile ?: return ""
    val document = PsiDocumentManager.getInstance(method.project).getDocument(containingFile) ?: return ""

    // 获取方法文本范围
    val methodTextRange = method.textRange
    val methodStartLine = document.getLineNumber(methodTextRange.startOffset)
    val methodEndLine = document.getLineNumber(methodTextRange.endOffset)

    // 计算预览范围：方法开始向上contextLines行，到方法结束向下contextLines行
    val previewStartLine = maxOf(0, methodStartLine - contextLines)
    val previewEndLine = minOf(document.lineCount - 1, methodEndLine + contextLines)

    // 提取预览文本
    val startOffset = document.getLineStartOffset(previewStartLine)
    val endOffset = document.getLineEndOffset(previewEndLine)
    val previewText = document.getText(TextRange(startOffset, endOffset))

    // 限制预览长度，避免过长的预览
    if (previewText.length > 2000) {
        val methodStartOffset = document.getLineStartOffset(methodStartLine)
        val methodEndOffset = document.getLineEndOffset(minOf(methodEndLine + contextLines, document.lineCount - 1))
        val methodText = document.getText(TextRange(methodStartOffset, methodEndOffset))
        if (methodText.length <= 2000) {
            return methodText
        }
        return methodText.substring(0, 2000) + "\n... (预览已截断)"
    }

    return previewText
}
```

fun getMethodPreviewFromElement(element: PsiElement, contextLines: Int = 3): String {
    val method = PsiTreeUtil.getParentOfType(element, Method::class.java)
    return if (method != null) getMethodPreviewText(method, contextLines) else ""
}

### 搜索关键词高亮

#### 高亮实现技术
```kotlin
private fun highlightSearchKeywordInEditor(editor: Editor, searchKeyword: String) {
    val document = editor.document
    val text = document.text
    val markupModel = editor.markupModel

    // 移除之前的高亮
    markupModel.removeAllHighlighters()

    // 查找并高亮所有匹配的关键词
    var index = 0
    while (index < text.length) {
        val foundIndex = text.indexOf(searchKeyword, index, ignoreCase = true)
        if (foundIndex == -1) break

        // 创建高亮属性
        val textAttributes = TextAttributes()
        textAttributes.backgroundColor = Color.YELLOW
        textAttributes.foregroundColor = Color.BLACK

        // 添加高亮
        markupModel.addRangeHighlighter(
            foundIndex,
            foundIndex + searchKeyword.length,
            HighlighterLayer.SELECTION - 1,
            textAttributes,
            HighlighterTargetArea.EXACT_RANGE
        )

        index = foundIndex + searchKeyword.length
    }
}
```

### UI 交互逻辑

#### 树选择监听器
```kotlin
tree.addTreeSelectionListener(object : TreeSelectionListener {
    override fun valueChanged(e: TreeSelectionEvent) {
        val selectedNode = tree.lastSelectedPathComponent as? DefaultMutableTreeNode
        if (selectedNode?.userObject is DisplayItem) {
            val selectedItem = selectedNode.userObject as DisplayItem

            // 释放之前的编辑器
            AutoDiscoverUiHelper.releaseEditor(editorHolder.editor)
            editorHolder.editor = null

            // 获取目标方法进行预览
            val element = getPsiElementFromItem(selectedItem)
            val method = PsiTreeUtil.getParentOfType(element, Method::class.java)

            if (method != null) {
                // 创建新的编辑器预览
                val newEditor = AutoDiscoverUiHelper.createEditorForMethodPreview(project, method, title)
                showEditorInPreview(newEditor)
            } else {
                showFallbackPreview(selectedItem.previewText)
            }
        } else {
            showDefaultPreviewMessage()
        }
    }
})
```

## 技术特点

### 性能优化
- **ReadAction保护**: 所有PSI读取操作都在ReadAction中执行，保证线程安全
- **异常处理**: 多层异常捕获，避免单个组件异常影响整体功能
- **资源管理**: 编辑器实例会被正确释放，避免内存泄漏

### 用户体验
- **渐进式回退**: 编辑器 -> 文本区域 -> 默认提示，保证功能可用性
- **配色一致性**: 预览编辑器使用与主编辑器相同的配色方案
- **智能定位**: 自动滚动到方法定义位置，光标定位到方法开始
- **上下文展示**: 显示方法及其前后几行的代码，便于理解调用上下文

### 可扩展性
- **插件化设计**: UI组件和预览逻辑分离，便于后续扩展
- **配置化参数**: 上下文行数、预览长度限制等均可配置
- **多格式支持**: 支持不同类型的高亮和预览格式

## 异常处理策略

### PSI解析异常
- 方法不存在时返回空字符串
- 文档获取失败时跳过预览
- PSI元素转换异常时记录日志但不中断流程

### UI组件异常
- 编辑器创建失败时自动回退到文本预览
- 配色方案设置失败时使用默认配色
- 高亮添加失败时跳过高亮功能

### 资源管理异常
- 编辑器释放失败时记录警告但不影响后续操作
- 文档监听器异常时自动清理相关资源
