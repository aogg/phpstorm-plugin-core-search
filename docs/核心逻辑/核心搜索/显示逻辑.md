# 核心搜索二级菜单显示逻辑

## 显示规则总结

@core二级菜单的显示遵循以下条件：
1. **文件类型检查**：当前文件必须是PHP文件（扩展名为.php）
2. **类存在检查**：文件中必须包含至少一个PHP类
3. **@core注解检查**：类或其继承链中必须有public方法包含@core注解
4. **关键词收集**：从类及其所有父类中提取@core关键词，去重后按字母排序显示

## 正面案例

### 案例1：基础@core注解
```php
<?php
class UserService {
    /**
     * 用户登录
     * @core login
     */
    public function login($username, $password) {
        // 登录逻辑
    }

    /**
     * 用户注册
     * @core register
     * @core user
     */
    public function register($data) {
        // 注册逻辑
    }
}
```

**显示结果**：
- 搜索核心
  - login
  - register
  - user
  - ---
  - 自动发现

**说明**：从UserService类中提取到3个关键词（login、register、user），按字母排序显示。

### 案例2：继承链@core注解
```php
<?php
class BaseService {
    /**
     * 基础操作
     * @core base
     */
    public function baseOperation() {
        // 基础操作
    }
}

class UserService extends BaseService {
    /**
     * 用户登录
     * @core login
     */
    public function login($username, $password) {
        // 登录逻辑
    }
}
```

**显示结果**（在UserService类上右键）：
- 搜索核心
  - base
  - login
  - ---
  - 自动发现

**说明**：UserService继承自BaseService，会同时显示父类的@core关键词。

### 案例3：多行@core注解
```php
<?php
class PaymentService {
    /**
     * 处理支付
     * @core payment
     * @core transaction
     * @param string $method
     */
    public function processPayment($method) {
        // 支付处理逻辑
    }
}
```

**显示结果**：
- 搜索核心
  - payment
  - transaction
  - ---
  - 自动发现

**说明**：一个方法可以有多个@core注解，每个注解都会生成独立的关键词项。

### 案例4：非public方法不参与显示
```php
<?php
class InternalService {
    /**
     * 公开接口
     * @core public
     */
    public function publicMethod() {
        // 公开方法
    }

    /**
     * 私有方法（不会显示）
     * @core private
     */
    private function privateMethod() {
        // 私有方法
    }

    /**
     * 受保护方法（不会显示）
     * @core protected
     */
    protected function protectedMethod() {
        // 受保护方法
    }
}
```

**显示结果**：
- 搜索核心
  - public
  - ---
  - 自动发现

**说明**：只有public方法上的@core注解才会参与显示，private和protected方法会被忽略。

## 反面案例

### 案例1：非PHP文件
在`config.xml`文件上右键：
```xml
<config>
    <database host="localhost"/>
</config>
```

**显示结果**：不显示"搜索核心"菜单项

**说明**：只有PHP文件才会显示@core菜单。

### 案例2：PHP文件无类
```php
<?php
// 这是一个纯函数文件
function helper_function() {
    return "helper";
}
```

**显示结果**：
- 搜索核心
  - 未找到 PHP 类
  - ---
  - 自动发现

**说明**：文件没有包含PHP类，但仍会显示菜单（用于占位和自动发现功能）。

### 案例3：类中无@core注解
```php
<?php
class PlainService {
    /**
     * 普通方法注释
     * @param string $input
     */
    public function normalMethod($input) {
        // 普通方法
    }
}
```

**显示结果**：
- 搜索核心
  - 未找到 @core 注解
  - ---
  - 自动发现

**说明**：类中没有@core注解，但仍会显示菜单（用于占位和自动发现功能）。

### 案例4：@core注解格式错误
```php
<?php
class BadAnnotationService {
    /**
     * 错误的注解格式
     * @core
     * 缺少关键词
     */
    public function badAnnotation() {
        // 方法实现
    }

    /**
     * 错误的注解格式2
     * @ core login
     * 多余空格
     */
    public function badAnnotation2() {
        // 方法实现
    }
}
```

**显示结果**：
- 搜索核心
  - 未找到 @core 关键词
  - ---
  - 自动发现

**说明**：@core注解必须严格遵循`@core 关键词`格式，缺少关键词或格式错误都不会被识别。

## 去重逻辑详解

### 关键词去重
```php
<?php
class DuplicatedService {
    /**
     * 方法1
     * @core duplicate
     */
    public function method1() {}

    /**
     * 方法2
     * @core duplicate
     */
    public function method2() {}

    /**
     * 方法3
     * @core duplicate
     */
    public function method3() {}
}
```

**显示结果**：
- 搜索核心
  - duplicate
  - ---
  - 自动发现

**说明**：即使多个方法包含相同的@core关键词，最终只会显示一次该关键词。

### 继承链去重
```php
<?php
class ParentService {
    /**
     * 父类方法
     * @core common
     */
    public function parentMethod() {}
}

class ChildService extends ParentService {
    /**
     * 子类方法
     * @core common
     */
    public function childMethod() {}
}
```

**显示结果**（在ChildService类上右键）：
- 搜索核心
  - common
  - ---
  - 自动发现

**说明**：即使父类和子类都有相同的@core关键词，最终也只会显示一次。

## 特殊情况说明

1. **自动发现入口**：无论是否有@core注解，都会显示"自动发现"子菜单，用于根据方法名规则自动发现方法。

2. **占位提示**：当条件不满足时，会显示相应的提示信息，但菜单仍会显示以提供自动发现功能。

3. **循环继承保护**：在检查父类@core注解时，会检测循环引用，避免无限递归。

4. **方法可见性**：只有public方法的@core注解会被收集，private和protected方法会被忽略。
