# 自动发现三级选项显示规则

## 案例分析

### 正面案例（显示三级选项）

**场景1：类中有匹配的 public 方法**
```
配置规则：["get*", "set*", "is*"]
当前PHP类：
class User {
    public function getName() { ... }
    public function setName($name) { ... }
    public function isActive() { ... }
    public function save() { ... }
}
```
显示结果：三级菜单会显示 "get*", "set*", "is*" 三个选项
原因：类中有 public 方法 getName()、setName()、isActive() 分别匹配这三个规则

**场景2：通配符匹配**
```
配置规则：["handle*"]
当前PHP类：
class EventHandler {
    public function handleUserLogin($user) { ... }
    public function handleUserLogout($user) { ... }
    public function processData($data) { ... }
}
```
显示结果：三级菜单会显示 "handle*" 选项
原因：类中有两个 public 方法 handleUserLogin() 和 handleUserLogout() 都匹配 "handle*" 规则

### 反面案例（不显示三级选项）

**场景1：类中没有匹配的 public 方法**
```
配置规则：["get*", "set*"]
当前PHP类：
class UserService {
    public function save($user) { ... }
    public function delete($user) { ... }
    private function getUserById($id) { ... }
}
```
显示结果：三级菜单为空，只显示"正在加载自动发现..."占位符
原因：虽然有 private 方法 getUserById()，但只匹配 public 方法

**场景2：规则配置为空**
```
配置规则：[]
当前PHP类：
class User {
    public function getName() { ... }
    public function setName($name) { ... }
}
```
显示结果：三级菜单为空
原因：没有配置任何规则

**场景3：大小写敏感匹配失败**
```
配置规则：["Get*"] （大小写敏感）
当前PHP类：
class User {
    public function getName() { ... }
    public function getAge() { ... }
}
```
显示结果：三级菜单为空（假设配置为大小写敏感）
原因：方法名是 getName 而不是 GetName，规则不匹配

## 显示规则总结

### 核心条件
自动发现三级选项的显示遵循以下条件：

1. **配置规则存在**：AutoDiscoverSettings 中必须配置有规则列表（rules）
2. **类中有匹配的方法**：当前 PHP 类中至少存在一个 public 方法，其方法名匹配该规则
3. **方法可见性**：只有 public 方法参与匹配，private/protected 方法不参与

### 匹配逻辑
1. **通配符转换**：规则中的 `*` 被转换为正则表达式 `.*`
2. **正则匹配**：使用完整的正则表达式进行精确匹配
3. **前缀回退**：如果规则以 `*` 结尾且正则匹配失败，会尝试前缀匹配（startsWith）
4. **大小写处理**：根据 caseInsensitive 设置决定是否忽略大小写

### 缓存机制
- 使用文件修改时间戳作为缓存版本
- 文件内容不变时直接返回缓存结果
- 配置变更或文件修改时重新计算匹配规则

### 显示流程
1. 解析当前上下文中的 PHP 类
2. 获取配置的规则列表
3. 对每个规则检查类中是否有匹配的 public 方法
4. 将有匹配的方法的规则作为三级选项显示
5. 无匹配规则时显示占位符并后台加载
