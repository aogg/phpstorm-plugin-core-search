# 名词对应代码

本文档列出了项目中所有功能名词及其对应的代码文件地址。

## 核心功能

### 1. 核心搜索 (@core 注解搜索)

#### 1.1 右键菜单入口
- **文件**: [`src/main/java/com/aogg/core/search/action/CoreSearchAction.kt`](src/main/java/com/aogg/core/search/action/CoreSearchAction.kt)
- **功能**: 固定显示的核心搜索入口，作为二级菜单展示公开方法的 @core 关键词

#### 1.2 关键词搜索动作
- **文件**: [`src/main/java/com/aogg/core/search/action/CoreKeywordSearchAction.kt`](src/main/java/com/aogg/core/search/action/CoreKeywordSearchAction.kt)
- **功能**: 搜索调用当前类方法的位置，且调用处的方法有对应的 @core 关键词

#### 1.3 @core 注解解析
- **文件**: [`src/main/java/com/aogg/core/search/helper/CoreAnnotationHelper.kt`](src/main/java/com/aogg/core/search/helper/CoreAnnotationHelper.kt)
- **功能**: 解析 PHPDoc 中的 @core 关键词注解，支持继承链收集

## 核心逻辑流程

### 核心搜索流程
1. 右键菜单触发 → [`CoreSearchAction.kt`](src/main/java/com/aogg/core/search/action/CoreSearchAction.kt)
2. 解析 @core 注解 → [`CoreAnnotationHelper.kt`](src/main/java/com/aogg/core/search/helper/CoreAnnotationHelper.kt)
3. 执行关键词搜索 → [`CoreKeywordSearchAction.kt`](src/main/java/com/aogg/core/search/action/CoreKeywordSearchAction.kt)
4. 显示搜索结果 → [`CoreSearchResultsToolWindowFactory.kt`](src/main/java/com/aogg/core/search/ui/CoreSearchResultsToolWindowFactory.kt)

### 自动发现流程
1. 右键菜单触发 → [`AutoDiscoverActionGroup.kt`](src/main/java/com/aogg/core/search/action/AutoDiscoverActionGroup.kt)
2. 匹配方法名规则 → [`AutoDiscoverHelper.kt`](src/main/java/com/aogg/core/search/helper/AutoDiscoverHelper.kt)
3. 执行模式搜索 → [`AutoDiscoverPatternSearchAction.kt`](src/main/java/com/aogg/core/search/action/AutoDiscoverPatternSearchAction.kt)
4. 显示搜索结果 → [`AutoDiscoverUiHelper.kt`](src/main/java/com/aogg/core/search/helper/AutoDiscoverUiHelper.kt)

### 固定搜索流程
1. 右键菜单触发 → [`FixedSearchActionGroup.kt`](src/main/java/com/aogg/core/search/action/FixedSearchActionGroup.kt)
2. 选择搜索类型 → 各个 FixedSearch*Action
3. 执行搜索逻辑 → [`ObjectMethodSearchService.kt`](src/main/java/com/aogg/core/search/service/ObjectMethodSearchService.kt) 等
4. 显示搜索结果 → [`FixedSearchHelper.kt`](src/main/java/com/aogg/core/search/helper/FixedSearchHelper.kt)

## 关键技术点

### 1. PSI (Program Structure Interface)
- 用于解析 PHP 代码结构
- 主要在 [`CoreAnnotationHelper.kt`](src/main/java/com/aogg/core/search/helper/CoreAnnotationHelper.kt) 中使用

### 2. StubIndex
- 用于高效的全项目搜索
- 主要在 [`CoreAnnotationHelper.kt`](src/main/java/com/aogg/core/search/helper/CoreAnnotationHelper.kt) 的 `findMethodsByKeyword` 方法中使用

### 3. ReferencesSearch
- 用于查找方法引用
- 主要在 [`CoreKeywordSearchAction.kt`](src/main/java/com/aogg/core/search/action/CoreKeywordSearchAction.kt) 和 [`ObjectMethodSearchService.kt`](src/main/java/com/aogg/core/search/service/ObjectMethodSearchService.kt) 中使用

### 4. 缓存机制
- 文件修改时间戳缓存 → [`CoreAnnotationHelper.kt`](src/main/java/com/aogg/core/search/helper/CoreAnnotationHelper.kt)
- 规则匹配缓存 → [`AutoDiscoverHelper.kt`](src/main/java/com/aogg/core/search/helper/AutoDiscoverHelper.kt)

### 5. 类型推断
- 对象类型推断 → [`CoreKeywordSearchAction.kt`](src/main/java/com/aogg/core/search/action/CoreKeywordSearchAction.kt) 的 `getCallerType` 方法
- 继承关系检查 → [`CoreKeywordSearchAction.kt`](src/main/java/com/aogg/core/search/action/CoreKeywordSearchAction.kt) 的 `isClassRelated` 方法

### 6. 正则表达式
- 通配符转正则 → [`AutoDiscoverHelper.kt`](src/main/java/com/aogg/core/search/helper/AutoDiscoverHelper.kt) 的 `patternToRegex` 方法
- @core 注解解析 → [`CoreAnnotationHelper.kt`](src/main/java/com/aogg/core/search/helper/CoreAnnotationHelper.kt) 的 `CORE_PATTERN`
